# 01 — NFR 基准 harness + 基线 + CI 门禁

**What to build:** 冷启动耗时、常驻 RSS、稳态帧率、PTY 吞吐四组基准能在 CI 上自动跑起来，固化一组基线数字，并在回归超标时让 CI fail。终端/编辑器之外的能力不再凭"感觉流畅"判断，而是有可对比的达标证据。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 冷启动基准：从进程启动到主窗口首帧可交互的耗时，三平台各落一组基线
- [ ] RSS 基准：启动空工作区与典型工作区（1 个终端 + 1 个大文件编辑器）下的常驻内存，落基线
- [ ] 帧率基准：稳态滚动与空闲时的 FPS，落基线
- [ ] PTY 吞吐基准：大量字节灌入终端的渲染跟上速率，落基线
- [ ] CI job 跑上述基准并与基线比较，回归超阈值时 fail
- [ ] 基线数字与阈值记录在 docs/ 下可查（spec NFR 基准项）
